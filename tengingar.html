How it works

Three steps. Done for you.

01

Tell us which tools you use.

Write the names on the pilot form, or tick them below. None, or paper, is a fine answer too.

02

We connect them and test them with you.

On a short call with whoever is the admin of each tool. We test with real data before we call it done.

03

You get your system ready to use.

We hand it over with a checklist: what is connected, what X reads and writes, and how to switch it off.

Who does what

What you do, what we do.

You

  • Approve access when your tool asks.
  • Create a key when we ask, and paste it into our secure form.
  • Test it with us on the call.

We

  • Check every tool you name.
  • Connect it.
  • Set up a bridge if one is needed.
  • Hand it over with a checklist.

We never type your passwords

You sign in and approve. Keys go into our secure form, never by email or chat.

Encrypted keys

Keys are stored encrypted and only used on the server. The AI never sees them.

Always asks first

Anything that moves money, or that the AI does in another system, waits for your yes.

What we find

Four possible outcomes.

We check each tool you name and tell you the outcome before we start.

Ready connection

We have already built it. You approve access or paste a key, and it works the same day.

We set it up with your key or login

Your tool lets you create your own key. We guide you on a screen-share call. You create it and paste it in.

We build it, or bridge it

The tool has an API we have not built for yet. We build it, or bridge it with Zapier or Make first and replace the bridge later.

Not possible yet

We say so plainly and offer the honest alternative: a file export we import on a schedule, or email forwarding to an address X reads.

    Questions

    About connections

    I'm not technical. Who sets it up?

    We do, with you. On a short call you sign in and approve access. We connect it, test it with you and hand it over with a checklist.

    Is setup included?

    In the pilot, yes. After the pilot, setting up your connections is part of Quick start, which is included in Business. See Pricing.

    My tool is not on this page. Can you connect it?

    Probably. Tell us the name. If it has an API or an export, we can usually connect it. If we can't, we say so and offer the honest alternative.

    Do I have to leave my accounting system?

    No. X sends the invoices there. Your bookkeeper keeps working as before.

    Do my tools cost extra?

    You keep paying your own tools directly. Some only allow connections on certain plans, Payday Premium or higher for example. We tell you before we start.

    Does X send e-invoices?

    X prepares the invoice and hands it to your accounting system or certified e-invoice provider, which issues it. X does not fiscalise invoices itself.

    I make software. Can I connect to X?

    Yes. Read about building a connection to X.
